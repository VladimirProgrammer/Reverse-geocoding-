# Reverse-geocoding-

Reverse geocoding
This is an educational project based.
In this project the reversed geocoding has been used so that you can type the latitude and longitude of a particular place and if found, the flag of this country and some data will appear on the screen.
Tools:
JScript, HTML, CSS - have been taken from jonasschmedtmann
https://api.bigdatacloud.net has been used for reverse geocoding
